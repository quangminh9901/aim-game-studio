User Guide

What is AIM Game Studio?

AIM Game Studio is a visual interface for managing game development projects using the Claude Code Game Studios framework. Instead of typing commands in a terminal, you interact through a chat interface with clickable options.

Getting Started

  • Create a Project: Click "New Project" in the sidebar or type "new project" in chat. The assistant will guide you step by step.
  • Choose Engine: Pick Godot, Unity, or Unreal. Each has different strengths - the assistant explains them.
  • Configure: Set team size, project name, and game genre through clickable cards.
  • Get Config: At the end, you get a ready-to-use configuration file.

Using Templates

Templates are pre-configured project setups for common game types. Click any template to start with recommended settings.

Chat Commands

  • new project - Start creating a new project
  • my projects - View saved projects
  • help - Show available commands
  • templates - Browse project templates
  • export [name] - Export a project config

For Non-Developers

You do NOT need any coding experience to use this tool. Everything is done through clicking and chatting. The configurations generated can be handed to a developer or used directly with Claude Code.

Deploying a New Project

  • Fork this repository on GitHub
  • The site auto-deploys via GitHub Pages
  • Your projects are saved in your browser
  • Export configs to share with your team

Help & FAQ

How do I create a game project?

Click "New Project" in the sidebar. The chat assistant will walk you through choosing an engine, setting up your team, and configuring your project step by step.

Do I need to know how to code?

No! This interface is designed for everyone. You make decisions by clicking options, and the system generates the technical configuration automatically.

Where are my projects saved?

Projects are saved in your browser's local storage. They persist between visits but are specific to this browser. Use the "Export" feature to save a backup.

How do I use the generated config?

The config file (project.yaml) goes into a Claude Code Game Studios project. You can either:

  • Copy it and give it to your developer
  • Place it in a cloned CCGS repository
  • Use it with Claude Code directly

Can I share this with my team?

Yes! Fork this repository on GitHub and each team member gets their own instance. Projects can be exported/imported as files.

What engines are supported?

Godot 4 (free, lightweight, GDScript), Unity (C#, large ecosystem), and Unreal Engine 5 (C++/Blueprint, AAA quality).
